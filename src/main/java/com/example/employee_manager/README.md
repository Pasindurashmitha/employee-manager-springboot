# Employee Manager Application

A Spring Boot CRUD application for managing employee details using MySQL.

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Thymeleaf
- HTML and CSS
- Lombok

## Features

- Add new employees
- View all employees
- Update employee details
- Delete employees
- REST API using JSON
- MySQL database integration
- Form validation

## How to Run

1. Start MySQL using XAMPP.
2. Open the project in Visual Studio Code.
3. Run `EmployeeManagerApplication.java`.
